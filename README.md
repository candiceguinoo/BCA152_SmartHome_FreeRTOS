# BCA152 Smart Home and FreeRTOS Multisensor Project

This repository contains my Smart Home and FreeRTOS Multisensor laboratory activities based on Chapter 9 of *Developing IoT Projects with ESP32, 2nd Edition*.

## Project Components

- **Smart Switch:** ESP32-based smart switch project.
- **Multisensor:** ESP32-S3-based multisensor system using FreeRTOS.

## Development Tools

- Visual Studio Code
- PlatformIO
- ESP32 / ESP32-S3
- Wokwi Simulator
- FreeRTOS
- Git and GitHub

## Laboratory Progress

Each important development step, test, correction, and improvement will be committed to this repository to document the progress of the project.
